# Founders Bay

Coming soon page for Founders Bay, a startup enablement partner for founders in the UAE.

A single static file (`index.html`) with the logo embedded. No build step, no dependencies. Fonts load from Google Fonts.

## Deploy on Vercel

1. Import this repository at https://vercel.com/new
2. Framework preset: Other. Leave build command and output directory empty.
3. Deploy, then add `foundersbay.com` under Project Settings, Domains.

## Edit

Brand tokens sit at the top of the `<style>` block in `index.html` (Deep Harbor, Tide, Crest, Paper, Mist). The contact address appears in the hero and in the copy script at the bottom of the file.
